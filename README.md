# Plantillas typst

La finalidad de este repositorio es recopilar diversas plantillas de documentos en el lenguaje typst. 
Cada plantilla está autocontenida en directorios individuales.
Todas las plantillas deben tener una guía de uso en el archivo `GUIA_USO.md` que servirá como documentación para que la adaptación de cualquier persona a la plantilla sea lo más cómoda posible.

## Creación de plantillas

Se recomienda seguir las pautas establecidas en el archivo `TYPST_POLICY.md`, que contiene pautas generales para el formato de elementos del docuemento y la estructura de los ficheros. Los agentes de inteligencia artificial, como por ejemplo, Claude Code, incrementan su eficacia a la hora de crear plantillas cuando usan estas reglas como referencia.

Todo el mundo es bienvenido a aportar sus plantillas personales que quiera compartir en este repositorio, siempre y cuando siguan las reglas establecidas anteriormente y no pisen ninguna plantilla ya subida por otro usuario. 

Todas las plantillas de este repositorio son de uso público, y cualquier persona tiene permiso para usar las plantillas siempre que quieran. Si no quieres que tu plantilla sea de uso público, no la subas a este repositorio.
